# enterprise-intelligence-layer

Design artefacts for an enterprise intelligence layer: one index across
Confluence, Jira, Bitbucket, code, notes and PDFs, with hybrid lexical +
semantic retrieval, delta ingestion, and ACL-correct serving — running behind a
corporate proxy with no admin rights on the machine.

**This repository is design-only.** No implementation code.

## Design tracks

Multiple independent architecture proposals land here as branches and pull
requests, so they can be compared rather than blended. See the open pull
requests.

| Track | Branch |
|---|---|
| Opus — architecture, ACL, delta correctness, capacity | `design/opus-architecture` |
